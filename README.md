# Authoring a Website - Class Code Repository

Welcome to the class GitHub repository.

This repository contains the code examples, demonstrations, and practical exercises completed during class sessions. You are encouraged to reuse, adapt, and build upon any of the code provided here for your own learning and development.

Where practical, live coding demonstrations will be recorded during class. However, if a recording is unavailable for any reason, the corresponding source code will still be uploaded to this repository so you do not miss out on the material covered.

⭐ **Please bookmark or star this repository** and check back regularly, as new content will be added throughout the semester.

## Repository Structure

Content will be organised by teaching week using the following naming convention:

```text
week_X_themeofweek
```

Examples:

```text
week_01_introduction
week_02_python_basics
week_03_object_oriented_programming
```

Each weekly folder will contain the code, examples, and supporting material relevant to that week's topic.

Happy coding!
